### 🏠 [Roomie (ស្រុកខ្ញុំ - SrokNh)](https://sroknh.com)
> A high-performance, mobile-first rental housing platform connecting tenants, students, and landlords across all **25 provinces in Cambodia** 🇰🇭.

- **Stack:** Built with **Nuxt 4**, **Vue 3**, and **TypeScript** (strict mode) on Nitro Server
- **Database & Storage:** **Supabase** (PostgreSQL with Row Level Security & image bucket storage)
- **Auth & Maps:** Google OAuth via **Clerk**; interactive map search & pin selection with **Leaflet** & **CARTO**
- **Bilingual:** Native Khmer (`km`) & English (`en`) with clean URLs and localized SEO
- **My Contributions:** Responsive UI/UX, user profile view/edit, listing location mapping, and core rental calculations

### 💸 [Personal Finance Tracker](https://github.com/srossongha/personal-finance-tracker)
> A modern full-stack financial dashboard for tracking income and expenses, monitoring category budgets, and analyzing cash flow trends.

- **Stack:** Built with **Next.js 16 (App Router)**, **React 19**, and **Tailwind CSS v4**
- **Database & Auth:** **Neon Serverless Postgres** paired with **Prisma 7**; cookie session security via **Better Auth**
- **Interactive Visualizations:** Custom SVG balance area charts with dynamic range switching (7D to 1Y) and category expense donut charts
- **Budgets & Alerts:** User-specific spending caps, real-time warning indicators (80%+ threshold), and notification dropdowns
- **Data Management:** Paginated transaction history with instant optimistic actions and CSV export
